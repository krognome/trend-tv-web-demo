# Demo art (temporary — remove before any real launch)

Every image in this folder is a **crop of an approved reference mockup**
from `specs/trend-tv/trend-tv-checkout-library/` — the AI-generated
photography baked into those 6 screens, isolated from the UI chrome
(nav bars, buttons, titles, badges) drawn on top of it in the original
composites.

**Why this exists:** `@trend-tv/fixtures`' artwork URIs intentionally
point at a non-resolving host (`fixtures.trend.tv` — see
`packages/fixtures/src/scenarios/artwork.ts`'s header comment), so every
card in this fixture-mode app degrades to a placeholder. That's correct
per the spec's fixture-adapter rule, but made early visual review harder
to read. These crops exist purely so `SafeImage.tsx` has something
nicer than a flat box to show while browsing the fixture-mode app.

**Why this is scoped to `apps/tv-web` only, not `@trend-tv/fixtures`:**
`.cursorrules` Section 3 is explicit — *"Do NOT use static UI mockups
(the .png files) as backgrounds; use them ONLY as layout/hierarchy
references."* The color/spacing/typography values sampled from these
same mockups (`@trend-tv/design-tokens`) are the compliant way to
"look like" them; using the mockup photography itself as if it were
real creator/product content is not, since the people and products
shown are AI-generated illustrations, not real TREND creators or
inventory. Keeping the substitution entirely inside this app's
presentation-layer `SafeImage.tsx` (never touching the shared,
platform-agnostic `@trend-tv/fixtures`/`@trend-tv/entities` packages
`apps/tv-native` also depends on) means:

- `apps/tv-native` is completely unaffected.
- Nothing here is treated as authoritative data — it is a rendering
  decoration keyed only by *media kind* (video/image/live/audio), never
  by entity id, title, or any real attribution field.
- Deleting this folder and `SafeImage.tsx`'s `DEMO_ART`/`pickDemoArt`
  block reverts cleanly to the icon+texture placeholder — a one-file
  change, the same "one-line change per entity" swap-out property the
  fixtures package's own header comment already promises for real
  cropped artwork later.
